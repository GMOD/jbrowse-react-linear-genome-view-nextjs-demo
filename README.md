# Next.js with @jbrowse/react-linear-genome-view2

`@jbrowse/react-linear-genome-view2` v5 (currently the `next` prerelease on npm) in a [Next.js](https://nextjs.org/) app router page, exported as a static site. The page is a client component.

See it running at https://jbrowse.org/demos/lgv-nextjs/.

## Usage

```bash
pnpm install
pnpm dev
```

`pnpm build` writes a static site.

More examples: https://jbrowse.org/storybook/, and the
[embedding guide](https://jbrowse.org/jb2/docs/embedded_components/).
